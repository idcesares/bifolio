# M6 performance and size

Date: 2026-10-22. Build: `./gradlew :app:assembleRelease` (R8 full mode, resource shrinking, ABI splits, unsigned).

## PRF-06 size per ABI

| ABI | APK bytes | MB |
|---|---|---|
| arm64-v8a | 3,872,367 | 3.69 |
| armeabi-v7a | 3,870,443 | 3.69 |
| x86_64 | 3,871,425 | 3.69 |

Budget: under 8 MB per ABI. Result: pass with 4.3 MB of headroom. The 12.3 MB figure from the M5 handoff was the
universal APK, before R8 and shrinking. Universal APK output is now disabled (`isUniversalApk = false`).

Owner note (2026-10-22): size accepted as not a blocker, even before this measurement.

## PRF-01 cold start (SM-F976B, Android 17, release with R8, 5 iterations)

Historical: measured with the `:benchmark` StartupBenchmark, since removed (owner decision 2026-10-25). Time to initial display:

| Compilation | min | median | max |
|---|---|---|---|
| None | 202 ms | 211 ms | 214 ms |
| Baseline profile (Partial) | 155 ms | 168 ms | 181 ms |

Budget: under 400 ms (P50). Result: pass, 168 ms with the profile. The module and the command are gone.
(the `benchmark` build type was removed too).

## Release with R8 on device

Release arm64 APK (debug-signed copy) installed on the SM-F976B. Launched, opened the math corpus
(`math-inline-display`, `math-errors`), no crash and no `ClassNotFound`/`NoSuchMethod` in logcat. No keep rules needed.

Isaac ran the device checks listed in `docs/RELEASE.md` on the SM-F976B and reported no problems: PRF-02 to PRF-05
(open time, page turn jank, re-pagination, heap), TalkBack on paged semantics, 200% font scale, hardware keyboard, and
