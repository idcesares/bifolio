# M6 performance and size

Date: 2026-10-22. Build: `./gradlew :app:assembleRelease` (R8 full mode, resource shrinking, ABI splits, unsigned).

## PRF-06 size per ABI

| ABI | APK bytes | MB |
|---|---|---|
| arm64-v8a | 3,872,367 | 3.69 |
| armeabi-v7a | 3,870,443 | 3.69 |
| x86_64 | 3,871,425 | 3.69 |

Budget: under 8 MB per ABI. Result: pass with 4.3 MB of headroom. The 12.3 MB figure from the M5 handoff was the
universal APK, before R8 and shrinking. Universal APK output is now disabled (`isUniversalApk = false`).

Owner note (2026-10-22): size accepted as not a blocker, even before this measurement.

## PRF-07 release configuration

- R8 full mode (AGP default), `isMinifyEnabled` and `isShrinkResources` on for `release`.
- `app/proguard-rules.pro` has no keep rules. Add one only with the release failure that justifies it.
- Baseline and startup profile: generator module exists (`:baselineprofile`); generation needs a device.
